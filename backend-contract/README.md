# PromptShop Backend Contract

Modular backend contract for the PromptShop AI Workflow Marketplace.

Core domain: Department -> Role -> RolePackage -> Prompt -> PromptVersion -> QualityRun.
Commerce domain: User -> Order -> Payment -> Entitlement -> Library.

Principles: outcome-first, role-first, server-side entitlement checks, provider adapters, versioned content, auditable analytics.
