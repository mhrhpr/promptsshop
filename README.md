# PromptShop — OMIND Frontend

Minimal RTL Next.js App Router frontend for the PromptShop AI Workflow Marketplace.

## Brand
- OMIND parent brand
- PromptShop product
- Dark / black base with electric-neon blue accents
- Lightweight SVG loop-arrow mark

## UX contract
1. Role-first: Home → Role → Workflow → Use
2. Problem-first: Search → Workflow → Use
3. Pack-first: Home → Pack → Workflow → Use

The current frontend is intentionally backend-agnostic and uses typed local seed data. Backend/API wiring can be connected without changing the page information architecture.
